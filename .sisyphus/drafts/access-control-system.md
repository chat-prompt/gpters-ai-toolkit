# Draft: 외부 인원 접근을 위한 권한 관리 시스템

## 현재 상태 (파악 완료)

### 인증
- NextAuth v5 + Google OAuth
- `@gpters.org` 도메인만 허용 (하드코딩)
- 신규 사용자 → 자동으로 `viewer` 역할

### RBAC (이미 구현됨)
- 3단계 역할: `admin` > `editor` > `viewer`
- 10개 퍼미션 정의 (catalog:view/create/edit/delete, users:view/manage, admin:view/settings, metadata:view/manage)
- API 라우트별 퍼미션 체크 구현 완료
- 종합 테스트 커버리지 존재 (583줄)

### 데이터 모델
- `users` 테이블에 `role` 필드 (userRoleEnum)
- `catalog_items`에 `teamTag` (platform/ai/data/product/infra/general)
- `catalog_items`에 `status` (draft/published)
- 아이템별 접근 제어 없음 (현재는 역할 기반만)

### 현재 한계
1. 이메일 도메인이 `@gpters.org`로 하드코딩 → 외부 사용자 진입 불가
2. 아이템 레벨 접근 제어 없음 → 모든 사용자가 모든 아이템 열람 가능
3. 조직(Organization) 개념 없음
4. MCP 서버 접근도 동일한 인증 제약

## 사용자 요구사항 (확인 필요)

### 핵심 요청
- 외부 인원도 사용 가능하게 할 것
- 권한에 따라 사용할 수 있는 아이템이 달라야 함

### 확인이 필요한 사항
- [ ] "외부 인원"의 범위 (다른 회사? 개인 사용자?)
- [ ] 아이템 접근 제어 모델 (조직 기반? 태그/카테고리 기반? 개별 지정?)
- [ ] 기존 gpters.org 사용자에 미치는 영향
- [ ] MCP 서버도 동일한 접근 제어 적용할 것인지
- [ ] 과금/플랜 모델 존재 여부 (무료/유료 구분?)

## 확정된 요구사항 (1차 인터뷰)

### 외부 인원 범위
- **B2B 모델**: 다른 회사/조직의 팀원들
- 일반 개인 사용자(B2C)는 대상 아님

### 접근 제어 모델
- **조직(Organization) 기반 멀티테넌시**
- 각 조직이 자신의 아이템을 관리
- 일부 아이템만 외부에 공개 가능

### 기존 데이터 처리
- 기존 @gpters.org 아이템은 **내부 전용으로 유지**
- 외부에 공개할 것만 별도 설정

## 확정된 요구사항 (2차 인터뷰)

### 외부 인증 방식
- **Google OAuth 도메인 확장**: 조직별 허용 이메일 도메인 등록
- 예: GPTers → @gpters.org, 파트너사 → @partnercorp.com
- 해당 도메인 사용자가 Google 로그인 시 자동으로 조직에 배정

### 아이템 공개 수준 (3단계)
- **private**: 해당 조직 내부에서만 접근 가능
- **shared**: 특정 조직들에게만 공유 (조직 ID 지정)
- **public**: 모든 조직이 접근 가능 (마켓플레이스 형태)

### 조직 내 역할
- 기존 3단계 유지: `org_admin` / `org_editor` / `org_viewer`
- 조직 단위로 적용

## 확정된 요구사항 (3차 인터뷰)

### 슈퍼어드민
- **글로벌 admin (super_admin)** 역할 추가
- 기존 GPTers admin → super_admin으로 승격
- 모든 조직의 데이터 접근 + 조직 관리 권한

### 아이템 공유 방식
- **Fork (복사)**: 다른 조직의 아이템을 복사하여 자신의 조직에서 독립적으로 수정 가능
- 원본과의 연결 유지 (forked_from 참조) → 업데이트 알림 가능

### MCP 접근 제어
- **조직 기반 MCP**: MCP로 검색/조회 시 조직 권한에 따라 노출 아이템이 다름
- OAuth 토큰에 조직 정보 포함

### 과금 모델
- **없음**: 모든 조직 무료 사용, 권한 차이만 존재

## 확정된 요구사항 (최종)

### 조직 생성
- super_admin이 직접 생성 가능
- 셀프서비스 신청도 가능 (승인 필요)

### 복수 조직 소속
- 한 사용자가 여러 조직에 소속 가능
- 조직 전환하며 사용

### 도입 전략
- **전체 구현 (한번에)**:
  - Organization 모델 + 역할 체계
  - 아이템 접근 제어 (3단계: private/shared/public)
  - MCP 조직 기반 연동
  - Fork 기능
  - 기존 데이터 마이그레이션
