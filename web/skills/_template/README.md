# 스킬 이름

> 스킬에 대한 한 줄 설명

## 설치

```bash
cp -r skills/스킬이름 ~/.claude/skills/
```

## 사용법

```
/스킬이름
```

### 기본 사용

```
/스킬이름
> [사용자 입력 예시]
```

### 옵션과 함께 사용

```
/스킬이름 --옵션
```

## 예시

### 예시 1: 기본 사용

**입력:**
```
/스킬이름
> 예시 입력
```

**출력:**
```
예시 출력 결과
```

### 예시 2: 고급 사용

**입력:**
```
/스킬이름 --상세
> 더 복잡한 입력
```

**출력:**
```
더 상세한 출력 결과
```
