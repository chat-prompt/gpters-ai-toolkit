# 스킬 이름

## 목적

이 스킬의 목적과 언제 사용하면 좋은지 설명합니다.

## 동작 방식

1. 첫 번째 단계
2. 두 번째 단계
3. 세 번째 단계

## 입력

사용자로부터 필요한 입력:
- **필수**: 반드시 필요한 정보
- **선택**: 있으면 좋은 정보

## 출력

스킬 실행 결과물:
- 결과물 형태 설명

## 예시

```
사용자: /스킬이름 [입력]
결과: [예상 결과]
```

## 주의사항

- 주의할 점 1
- 주의할 점 2
