# case-study-writer

> AI/자동화 프로젝트 사례를 사내 공유용 게시글로 작성해주는 스킬

## 설치

```bash
cp -r skills/case-study-writer ~/.claude/skills/
```

## 사용법

```
/case-study-writer
```

대화형으로 정보를 수집하고 사례 게시글을 작성합니다.

## 예시

### 기본 사용

```
/case-study-writer
```

AI가 순차적으로 질문하며 정보를 수집합니다:
- 프로젝트명
- 배경/문제
- 해결 방법
- 결과

### 정보와 함께 사용

```
/case-study-writer

프로젝트: 주간보고 자동화
문제: 매주 보고서 취합에 2시간 소요
해결: Claude 슬랙 요약 스킬 적용
결과: 10분으로 단축
```

## 출력 예시

```markdown
# 주간보고 자동화 사례 공유

## 배경
매주 금요일, 각 팀의 주간 보고를 취합하여 경영진 보고서를
작성하는 데 약 2시간이 소요되었습니다. 슬랙 채널을 일일이
확인하고 중요 내용을 수동으로 정리해야 했기 때문입니다.

## 해결 방법
Claude Code를 활용하여 슬랙 메시지 자동 요약 스킬을
개발했습니다. 각 팀 채널의 주요 업데이트를 자동으로 수집하고
핵심 내용만 추출하여 정리합니다.

## 결과
- 소요 시간: 2시간 → 10분 (92% 감소)
- 누락 없이 모든 팀 업데이트 반영
- 일관된 형식으로 가독성 향상

## 배운 점
- 슬랙 API 연동 시 권한 설정에 주의 필요
- 요약 품질을 위해 프롬프트 튜닝이 중요
- 파일럿 테스트 후 점진적 확대 권장
```
