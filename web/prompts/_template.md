# 프롬프트 이름

> 프롬프트에 대한 한 줄 설명

## 메타데이터

- **담당자**: @이름
- **태그**: `#태그1` `#태그2`
- **버전**: 1.0.0
- **최종 수정**: YYYY-MM-DD

## 프롬프트

```
여기에 실제 프롬프트 내용을 작성합니다.

[변수1]: 사용자가 채워야 할 부분
[변수2]: 사용자가 채워야 할 부분

원하는 결과물에 대한 지시사항...
```

## 변수 설명

| 변수 | 필수 | 설명 | 예시 |
|------|------|------|------|
| [변수1] | O | 설명 | 예시값 |
| [변수2] | X | 설명 | 예시값 |

## 사용 예시

### 입력

```
[변수1] = "실제값1"
[변수2] = "실제값2"
```

### 예상 출력

```
예상되는 결과물 예시
```

## 팁

- 더 좋은 결과를 얻기 위한 팁 1
- 팁 2
