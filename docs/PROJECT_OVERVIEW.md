# GPTers AI Toolkit — 현재 프로젝트 개요

GPTers AI Toolkit은 코딩 에이전트용 스킬을 검색·공유하고, 팀의 AI 활용을 측정하는 플랫폼이다.
웹 애플리케이션, MCP 서버, AITK CLI, Claude Code·Codex·OpenCode 플러그인을 Turbo 모노레포로 운영한다.

## 현재 기준

- 카탈로그는 GPTers 단일 카탈로그 정책을 사용한다.
- AX 대시보드는 사내 AI 활용, 스킬 사용, 클라이언트 사용량, 구독과 배포 현황을 보여주는 운영 화면이다.
- 팀 스킬(aitk 카탈로그)과 에이전트 스킬(`bbopters-shared`)은 출처가 다르므로 합산하지 않는다.
- 에이전트 텔레메트리 API와 운영 저장 테이블은 파일럿 상태로 연결됐다. 현재 활동 잔디는 여전히
  Git 커밋 수 프록시이며, 검증된 실행 결과는 후속 0029–0030 스키마 적용 뒤 표시한다.

## 현재 작업 순서

1. 뽀둥이 timer-triggered 수집 2회를 검증하고 PR #33을 `main`에 정착시킨다.
2. 대시보드 고도화 통합 브랜치를 새 `main` 위로 재정렬한다.
3. Neon child branch에서 0026–0030과 Preview 화면을 검증한다.
4. 실측이 없는 지표는 추정값으로 채우지 않고 계측 계약부터 정한다.
5. 전역 타입체크와 테스트 환경 격리 등 저장소 품질 부채를 별도 작업으로 관리한다.
