# AX 자동 갱신과 관측 상태 구분

## 문제와 동작

열어 둔 대시보드가 갱신되지 않고, 캐시 재조회 실패도 드러나지 않아 오래된 수치를 현재 상태로 읽을 수 있었다. 수집기 정상은 업무 성공과 별개지만 일반적인 정상 배지로 표시됐다.

- 보이는 화면과 의존 패널을 60초마다 조회한다. 숨김 탭/오프라인에서는 자동 조회를 멈추고 복귀 시 즉시 재조회한다. 최초 지연 조회와 기간 선조회는 기존 동작을 유지한다.
- 진행 중 요청과 자동 조회를 중복하지 않고, 네트워크 요청은 30초 후 중단한다. 화면 이탈 시 요청과 타이머를 정리한다.
- 마지막 서버 조회 성공 시각은 현재 표시 데이터와 함께 저장한다. 활성 화면에 필요한 패널 중 가장 오래된 성공 시각을 표시하며, 일부가 아직 없으면 미완료로 표시한다. 원천 수집 시각은 별도로 표시한다.
- 네트워크/HTTP/패널 조회 실패 시 이전 데이터를 유지하며 오류를 표시한다. 권한 거절은 해당 패널의 이전 데이터를 제거한다. 기간 전환 실패는 이전 기간 자료가 남았음을 알린다.
- 새로고침 버튼은 일반 조회다. 관리자용 스킬 비교의 강제 갱신을 자동 호출하지 않는다.
- 수집 정상 소스 수와 최근 작업 목록의 실행 실패 관측을 구분한다. 실행 근거가 없으면 미수집이며, 실패 미관측을 전체 업무 성공으로 표시하지 않는다. 재시도 전 실패도 관측 건수에 포함된다.
- 백그라운드 갱신 중 필터와 열린 작업 상세를 유지한다.

## 검증

- 웹 단위 테스트 전체 123개 파일 / 2,679개 테스트 통과. API/E2E 변경 테스트는 실행하지 않았다.
- 새 자동 갱신 회귀 테스트 10개: 활성 화면 갱신, 상세 유지, 숨김/오프라인/복귀/정리, 캐시 재조회 실패, 패널 오류, 타임아웃, 오래된 탭 복귀, 권한 거절, 기간 실패/늦은 응답, 화면 이탈 후 선조회 중단.
- 수집 정상과 실행 실패 동시 표시 및 근거 부재 표시 테스트 추가.
- 로컬 Next.js와 합성 데이터로 데스크톱 밝은/어두운 테마, 390px 폭, 오류 안내와 데이터 유지, 실제 1분 자동 갱신에 따른 복구 및 열린 상세 유지를 확인했다. 데스크톱 가로 넘침 없음. 검수용 페이지는 로컬에만 유지하고 Git 추적에서 제외한다.
- 갱신 상태를 탭 아래 ‘화면 갱신’ 박스로 표시하고, 마지막 조회 시각에 초를 포함한다. 로컬 실패·복구 테스트 버튼은 응답 모드 전환과 즉시 조회를 함께 수행한다.
- 전체 타입 검사는 기존 테스트 fixture 오류로 통과하지 못한다. 테스트 파일을 제외한 앱 소스 타입 검사와 변경 파일 ESLint는 통과했다.

## 범위와 다음 작업

로컬 구현 및 검증 단계다. 운영 배포와 AITK/npm 발행은 별도다. 브라우저가 닫힌 동안 실행되는 중앙 감시나 알림은 구현하지 않는다. 원천 수집 주기는 바꾸지 않으므로 1분 화면 갱신이 1분 원천 수집을 의미하지 않는다.

다음은 기존 로컬 사고 검토 도구를 중앙의 문제 후보/조치 관리 화면으로 연결하는 작업이다. 실행·검증·전달 영수증과 장기 조회 범위는 후속으로 확장한다.
