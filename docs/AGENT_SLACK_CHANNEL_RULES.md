# Slack 에이전트 업무방 대화 규칙

이 문서는 이 저장소의 작업을 Slack 에이전트 업무방에서 요청·조율할 때 적용하는 공통 규칙이다.
채널 목록을 짧고 읽기 쉽게 유지하면서, 작업 맥락과 검증 기록은 잃지 않는 것이 목적이다.

## 기본 형식

에이전트 업무방의 **채널 원문**에는 아래 두 가지만 한 줄로 쓴다.

1. 작업할 에이전트 멘션
2. 대괄호 주제와 짧은 제목

```text
@에이전트 [주제] 한 줄 제목
```

채널 원문에 긴 배경, 단계별 명령, 로그, 체크리스트, 진행 상황, 최종 결과를 붙이지 않는다.

모든 상세 내용은 원문의 **스레드**에서 이어간다.

- 배경과 현재 상태
- 실행 요청과 보호 조건
- 진단·검증 절차
- 질문과 답변
- 중간 진행 상황과 최종 결과
- 관련 담당자 호출

민감정보, 토큰, 인증정보, 원문 transcript, 프롬프트·응답은 채널과 스레드 어디에도 평문으로 올리지 않는다.

## 뽀둥이 업무방

- 채널: `#023-뽀둥이-업무방`
- 뽀둥이 멘션: `<@U0AP03YMX18>`

권장 원문 형식:

```text
<@U0AP03YMX18> [텔레메트리] Claude Code 자동 수집 복구·2회 검증
```

작업이 시작된 뒤에는 새 채널 원문을 만들지 말고 기존 스레드에서 후속 대화를 계속한다.

이미 긴 원문을 올렸다면 상세 내용을 먼저 스레드 댓글로 옮긴 뒤, 원문을 멘션과 한 줄 제목으로
수정한다. 상세 내용을 보존하기 전에 원문부터 줄이지 않는다.

## 처음 사용하는 방

새로운 에이전트 방이거나 기존 대화 규칙을 확인할 수 없는 방에서는 규칙을 임의로 추측하지 않는다.
첫 상세 작업 요청을 보내기 전에 최하영님(`<@U0BP4R0CUSD>`)을 호출해 그 방의 대화 규칙을 확인한다.

```text
<@U0BP4R0CUSD> [채널 규칙 확인] 이 업무방의 원문·스레드 사용 규칙을 알려주세요
```

규칙이 확인되기 전에는 긴 작업 지시를 채널 원문에 게시하지 않는다. 새 규칙이 확정되면 이 문서에
해당 방의 멘션·제목 형식·스레드 규칙을 추가해 다음 작업자가 그대로 따를 수 있게 한다.
