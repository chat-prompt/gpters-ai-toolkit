# GPTers AI Toolkit - Claude Code Marketplace

Claude Code 플러그인 마켓플레이스입니다. GPTers 커뮤니티에서 만든 스킬, 에이전트, 커맨드를 설치할 수 있습니다.

## 설치 방법

### 1. 마켓플레이스 추가 (1회)

```bash
/plugin marketplace add gpters/gpters-ai-toolkit
```

### 2. 플러그인 설치

```bash
# 예: git-commit 스킬 설치
/plugin install git-commit@gpters-ai-toolkit

# 사용 가능한 플러그인 목록 보기
/plugin marketplace list gpters-ai-toolkit
```

### 3. 업데이트

```bash
/plugin marketplace update
```

## 플러그인 찾기

웹 카탈로그에서 더 많은 플러그인을 찾아보세요:
- [GPTers AI Toolkit 카탈로그](https://gpters-ai-toolkit.vercel.app)

## 플러그인 종류

| 타입 | 설명 |
|------|------|
| **Skill** | Claude가 특정 작업을 수행할 때 사용하는 스킬 |
| **Agent** | 특화된 역할을 수행하는 에이전트 |
| **Command** | `/command` 형태로 호출하는 명령어 |

## 기여하기

새로운 플러그인을 만들고 싶으시면:
1. [웹 카탈로그](https://gpters-ai-toolkit.vercel.app)에서 등록
2. 관리자 승인 후 마켓플레이스에 자동 동기화
