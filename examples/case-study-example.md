# 고객 문의 분류 자동화 사례 공유

## 배경

CS팀에서는 하루 평균 200건의 고객 문의를 처리하고 있습니다.
문의가 접수되면 담당자가 내용을 읽고 적절한 카테고리(배송/결제/상품/기타)로
분류한 후 해당 팀에 전달하는데, 이 분류 작업에만 하루 1시간 이상이 소요되었습니다.

특히 문의량이 많은 월요일이나 세일 기간에는 분류 지연으로 인해
응답 시간이 늘어나는 문제가 있었습니다.

## 해결 방법

Claude API를 활용한 자동 분류 시스템을 구축했습니다.

**적용 기술:**
- Claude 3.5 Sonnet API
- n8n 워크플로우 자동화
- Slack 연동

**동작 방식:**
1. 새 문의 접수 시 n8n 웹훅 트리거
2. Claude가 문의 내용 분석 및 카테고리 분류
3. 분류 결과에 따라 해당 팀 슬랙 채널에 자동 전달
4. 담당자 멘션으로 즉시 알림

## 결과

| 지표 | Before | After | 개선율 |
|------|--------|-------|--------|
| 분류 소요 시간 | 60분/일 | 0분 (자동) | 100% |
| 평균 응답 시간 | 4시간 | 2시간 | 50% |
| 분류 정확도 | 95% (수동) | 97% (AI) | +2%p |

**정성적 효과:**
- 담당자가 분류 업무에서 해방되어 실제 응대에 집중
- 24시간 자동 분류로 야간/주말 문의도 즉시 배정
- 분류 기준의 일관성 확보

## 배운 점

1. **프롬프트가 핵심**: 처음에는 분류 정확도가 80% 수준이었으나,
   실제 문의 예시를 프롬프트에 포함시키니 97%까지 향상

2. **예외 처리 중요**: 분류가 애매한 경우 "미분류" 카테고리로
   보내고 사람이 확인하도록 설계

3. **점진적 적용**: 처음 2주는 자동 분류 + 수동 검증을 병행하여
   신뢰도 확보 후 완전 자동화
