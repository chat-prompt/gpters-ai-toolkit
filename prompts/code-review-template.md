# Code Review Template

PR 리뷰 시 아래 체크리스트를 기반으로 리뷰해주세요.

## Checklist

### 기능성
- [ ] 요구사항을 충족하는가?
- [ ] 엣지 케이스를 처리하는가?
- [ ] 에러 핸들링이 적절한가?

### 코드 품질
- [ ] 코드가 읽기 쉬운가?
- [ ] 함수/클래스 이름이 명확한가?
- [ ] 중복 코드가 없는가?
- [ ] 주석이 필요한 곳에 있는가?

### 테스트
- [ ] 테스트가 작성되었는가?
- [ ] 테스트 커버리지가 충분한가?
- [ ] 테스트가 실제로 의미있는 검증을 하는가?

### 보안
- [ ] 입력값 검증이 되어있는가?
- [ ] 민감정보가 노출되지 않는가?
- [ ] SQL Injection, XSS 등 취약점이 없는가?

### 성능
- [ ] 불필요한 연산이 없는가?
- [ ] N+1 쿼리 문제가 없는가?
- [ ] 메모리 누수 가능성이 없는가?

## Review Comment Format

```
### [카테고리] - [심각도: Critical/Major/Minor/Suggestion]

**위치**: `파일명:라인번호`

**현재 코드**:
\`\`\`
// 문제가 되는 코드
\`\`\`

**제안**:
\`\`\`
// 개선된 코드
\`\`\`

**이유**: 왜 이 변경이 필요한지 설명
```

## Usage

1. 이 템플릿을 복사하세요
2. PR diff를 분석하세요
3. 체크리스트를 기반으로 리뷰하세요
4. Comment Format에 맞춰 피드백을 작성하세요
