# Data Source Reference

GPTers 플랫폼의 데이터 소스 레퍼런스 스킬입니다.

## 기능

- Portal DB (PostgreSQL) 테이블 구조 참조
- Airtable 베이스/테이블 ID 및 필드 정보 조회
- 데이터 동기화 방향 (Hightouch, N8N, Webhook) 안내
- ID 매핑 관계 (User, Payment, Study, CommunityPost)
- 개발 시 주의사항 제공

## 설치

```bash
# 마켓플레이스 추가 (최초 1회)
/plugin marketplace add chat-prompt/gpters-ai-toolkit

# 플러그인 설치
/plugin install data-source-reference@gpters-ai-toolkit
```

## 사용 예시

- "User 테이블 구조가 어떻게 되어 있어?"
- "결제 데이터는 어디서 관리해?"
- "Airtable과 Portal DB 동기화는 어떻게 되지?"
- "기수관리 테이블 필드 정보 알려줘"
- "멤버(Sync) 테이블의 Field ID가 뭐야?"
